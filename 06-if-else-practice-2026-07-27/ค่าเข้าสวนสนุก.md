# ค่าเข้าสวนสนุก

[← กลับหน้าหลัก](../README.md) · [ดาวน์โหลดไฟล์ Flowgorithm](<./ค่าเข้าสวนสนุก.fprg>)

> **แบบฝึก:** 07/27/2026 · **อัปเดตล่าสุด:** 07/30/2026

## โจทย์

รับอายุและส่วนสูงของผู้เข้าชม แล้วกำหนดราคาบัตรเข้าสวนสนุกตามเงื่อนไข

**แนวคิดที่ฝึก:** การตรวจข้อมูลด้วย `Do...Loop` และการใช้ `If...Else` แบบซ้อนเพื่อตรวจหลายเงื่อนไข

## ผังงานจาก Flowgorithm

## Pseudocode

```text
เริ่มต้น
    ประกาศ Integer age, height, ticketprice

    ทำซ้ำ
        แสดงผล "Enter Age (years)"
        รับค่า age
    ขณะที่ age <= 0

    ทำซ้ำ
        แสดงผล "Enter Height (cm)"
        รับค่า height
    ขณะที่ height <= 0

    ถ้า age < 5 แล้ว
        ticketprice = 0
    มิฉะนั้น
        ถ้า age <= 12 แล้ว
            ถ้า height < 120 แล้ว
                ticketprice = 100
            มิฉะนั้น
                ticketprice = 150
            จบเงื่อนไข
        มิฉะนั้น
            ticketprice = 250
        จบเงื่อนไข
    จบเงื่อนไข

    แสดงผล "Ticket Price = " & ticketprice & " Baht"
จบการทำงาน
```
