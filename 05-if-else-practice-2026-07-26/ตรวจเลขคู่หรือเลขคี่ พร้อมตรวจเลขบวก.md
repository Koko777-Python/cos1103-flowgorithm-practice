# ตรวจเลขคู่หรือเลขคี่ พร้อมตรวจเลขบวก

[← กลับหน้าหลัก](../README.md) · [ดาวน์โหลดไฟล์ Flowgorithm](<./ตรวจเลขคู่หรือเลขคี่ พร้อมตรวจเลขบวก.fprg>)

> **สถานะ:** บันทึกตามไฟล์ต้นฉบับของวันที่ 07/26/2026

## โจทย์

รับจำนวนเต็ม ตรวจว่าเป็นจำนวนบวกก่อน แล้วจึงตรวจว่าเป็นเลขคู่หรือเลขคี่

**แนวคิดที่ฝึก:** การใช้ `If...Else` แบบซ้อนและตัวดำเนินการ `Mod`

> ภาพหน้าจอนี้จับคู่กับไฟล์ `ตรวจเลขคู่หรือเลขคี่ พร้อมตรวจเลขบวก.fprg` ตามชื่อเดียวกัน

## Pseudocode

```text
เริ่มต้น
    ประกาศ Integer number
    แสดงผล "Enter Number"
    รับค่า number

    ถ้า number > 0 แล้ว
        ถ้า number Mod 2 = 0 แล้ว
            แสดงผล "Positive Even"
        มิฉะนั้น
            แสดงผล "Positive Odd"
        จบเงื่อนไข
    มิฉะนั้น
        แสดงผล "Invalid Number"
    จบเงื่อนไข
จบการทำงาน
```
