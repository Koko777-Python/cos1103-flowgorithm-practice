[← กลับหน้าหลัก](../README.md) · [ดาวน์โหลดไฟล์ Flowgorithm](<./หาค่ามากที่สุดจาก 3 จำนวน.fprg>)

> **วันที่บันทึก:** 07/28/2026

## โจทย์

รับจำนวนเต็ม 3 ค่า แล้วหาค่าที่มากที่สุดด้วยเงื่อนไขแบบซ้อน

**แนวคิดที่ฝึก:** การเปรียบเทียบหลายค่าและการใช้ `If...Else` แบบซ้อน

## Pseudocode

```text
เริ่มต้น
    ประกาศ Integer A, B, C, Maximum

    แสดงผล "Enter A"
    รับค่า A
    แสดงผล "Enter B"
    รับค่า B
    แสดงผล "Enter C"
    รับค่า C

    ถ้า A >= B แล้ว
        ถ้า A >= C แล้ว
            Maximum = A
        มิฉะนั้น
            Maximum = C
        จบเงื่อนไข
    มิฉะนั้น
        ถ้า B >= C แล้ว
            Maximum = B
        มิฉะนั้น
            Maximum = C
        จบเงื่อนไข
    จบเงื่อนไข

    แสดงผล "Maximum = " & Maximum
จบการทำงาน
```
