# ตรวจคะแนนและตัดเกรด

[← กลับหน้าหลัก](../README.md) · [ดาวน์โหลดไฟล์ Flowgorithm](<./ตรวจคะแนนและตัดเกรด.fprg>)

> **สถานะ:** บันทึกตามไฟล์ต้นฉบับของวันที่ 07/26/2026

## โจทย์

รับคะแนน ตรวจสอบช่วง 0–100 แล้วแสดงเกรด A, B, C, D หรือ F

**แนวคิดที่ฝึก:** การตรวจช่วงข้อมูลและเลือกหลายกรณีด้วย `If...Else` แบบซ้อน

## ผังงานจาก Flowgorithm

![ผังงาน ตรวจคะแนนและตัดเกรด](<./images/ตรวจคะแนนและตัดเกรด.png>)

## Pseudocode

```text
เริ่มต้น
    ประกาศ Integer Score
    แสดงผล "Enter Score"
    รับค่า score

    ถ้า score >= 0 และ score <= 100 แล้ว
        ถ้า score >= 80 และ score <= 100 แล้ว
            แสดงผล "A"
        มิฉะนั้น ถ้า score >= 70 และ score <= 79 แล้ว
            แสดงผล "B"
        มิฉะนั้น ถ้า score >= 60 และ score <= 69 แล้ว
            แสดงผล "C"
        มิฉะนั้น ถ้า score >= 50 และ score <= 59 หรือ score > 50 แล้ว
            แสดงผล "D"
        มิฉะนั้น
            แสดงผล "F"
        จบเงื่อนไข
    มิฉะนั้น
        แสดงผล "Invalid score"
    จบเงื่อนไข
จบการทำงาน
```
