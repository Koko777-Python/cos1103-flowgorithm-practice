# ระบบคิดค่าไฟฟ้าแบบขั้นบันได

[← กลับหน้าหลัก](../README.md) · [ดาวน์โหลดไฟล์ Flowgorithm](<./ระบบคิดค่าไฟฟ้าแบบขั้นบันได.fprg>)

> **วันที่บันทึก:** 07/28/2026

## โจทย์

รับจำนวนหน่วยไฟฟ้า กำหนดอัตราค่าไฟตามช่วง และคำนวณค่าไฟตามเงื่อนไขในโปรแกรม

**แนวคิดที่ฝึก:** การใช้ `If...Else` แบบซ้อนและการตรวจช่วงข้อมูล

## Pseudocode

```text
เริ่มต้น
    ประกาศ Integer unit, rate, bill

    แสดงผล "Enter Unit"
    รับค่า unit

    ถ้า unit > 0 แล้ว
        ถ้า unit >= 0 และ unit <= 100 แล้ว
            rate = 3
        มิฉะนั้น
            ถ้า unit >= 101 และ unit <= 300 แล้ว
                rate = 5
            มิฉะนั้น
                rate = 7
            จบเงื่อนไข
        จบเงื่อนไข
    มิฉะนั้น
        แสดงผล "Invalid unit"
        bill = 0
        unit = 0
        rate = 0
    จบเงื่อนไข

    bill = unit * rate
    แสดงผล "Electricity Unit = " & unit & " Unit"
    แสดงผล "Rate = " & rate & " Baht"
    แสดงผล "Bill = " & bill & " Baht"
จบการทำงาน
```
