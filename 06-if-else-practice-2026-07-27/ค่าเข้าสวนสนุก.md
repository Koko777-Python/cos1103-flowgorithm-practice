# ค่าเข้าสวนสนุก

[← กลับหน้าหลัก](../README.md) · [ดาวน์โหลดไฟล์ Flowgorithm](<./ค่าเข้าสวนสนุก.fprg>)

> **สถานะ:** บันทึกตามไฟล์ต้นฉบับของวันที่ 07/27/2026

## โจทย์

รับอายุและส่วนสูงของผู้เข้าชม แล้วกำหนดราคาบัตรเข้าสวนสนุกตามเงื่อนไข

**แนวคิดที่ฝึก:** การใช้ `If...Else` แบบซ้อนเพื่อตรวจหลายเงื่อนไข

## ผังงานจาก Flowgorithm

![ผังงาน ค่าเข้าสวนสนุก](<./images/ค่าเข้าสวนสนุก.png>)

> ภาพหน้าจอนี้จับคู่กับไฟล์ `ค่าเข้าสวนสนุก.fprg` ตามชื่อเดียวกัน

## Pseudocode

```text
เริ่มต้น
    ประกาศ Integer age, height, ticketprice

    แสดงผล "Enter Age"
    รับค่า age
    แสดงผล "Enter Height"
    รับค่า height

    ถ้า age >= 0 และ age < 5 แล้ว
        ticketprice = 0
    มิฉะนั้น
        ถ้า age >= 5 และ age <= 12 แล้ว
            ถ้า height >= 0 และ height < 120 แล้ว
                ticketprice = 100
            มิฉะนั้น
                ticketprice = 150
            จบเงื่อนไข
        มิฉะนั้น
            ticketprice = 250
        จบเงื่อนไข
    จบเงื่อนไข

    แสดงผล "Ticket Price = " & ticketprice & " Baht"
จบการทำงาน
```
